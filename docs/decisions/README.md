# Architecture Decision Records

One decision per file, named `NNNN-short-title.md`. Keep decisions small and
dated; change a decision only by adding a new record that supersedes it.

## Template

```markdown
# NNNN — Title

- **Status:** Proposed | Accepted | Superseded by NNNN
- **Date:** YYYY-MM-DD

## Context

What situation or constraint forced a decision?

## Decision

What was decided, precisely enough to implement and verify.

## Consequences

What becomes easier, harder, or forbidden as a result?
```
